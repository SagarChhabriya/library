## 1 Core Concepts

| Term                         | Description                                                                              |
| ---------------------------- | ---------------------------------------------------------------------------------------- |
| Machine Learning (ML)        | Teaching computers to learn from data and make predictions without explicit programming. |
| Artificial Intelligence (AI) | Broad field of making machines “intelligent,” ML is a subset.                            |
| Model                        | Mathematical system that learns patterns from data.                                      |
| Algorithm                    | The method or process used to train a model.                                             |
| Training                     | Process of teaching the model using data.                                                |
| Prediction                   | The output or decision made by the trained model.                                        |
| Learning                     | The process of improving predictions based on data.                                      |
| Pattern                      | The recurring structure or relationship in data that the model learns.                   |
| Generalization               | Model’s ability to perform well on new, unseen data.                                     |


## 2 Data-Related Terms

| Term              | Description                                                    |
| ----------------- | -------------------------------------------------------------- |
| Dataset           | Collection of data used for training, validation, and testing. |
| Data Point        | A single observation or row in the dataset.                    |
| Sample            | Another word for a data point; one instance of data.           |
| Observation       | Same as data point; a recorded instance of data.               |
| Feature (X)       | Input variable used to make predictions.                       |
| Label (Y)         | Output variable that the model is trying to predict.           |
| Target Variable   | Same as label; what we want to predict.                        |
| Input             | Features provided to the model.                                |
| Output            | Result predicted by the model.                                 |
| Structured Data   | Data organized in rows and columns.                            |
| Unstructured Data | Data like text, images, audio, not in tabular format.          |


## 3 Types of Machine Learning

| Term                   | Description                                              |
| ---------------------- | -------------------------------------------------------- |
| Supervised Learning    | Learning with labeled data (input → output).             |
| Unsupervised Learning  | Learning without labels; finding patterns/clusters.      |
| Reinforcement Learning | Learning by trial and error using rewards/punishments.   |
| Classification         | Predicting discrete categories (e.g., spam or not spam). |
| Regression             | Predicting continuous values (e.g., house prices).       |
| Clustering             | Grouping similar data points together.                   |


## 4 Training & Evaluation Terms

| Term             | Description                                                                |
| ---------------- | -------------------------------------------------------------------------- |
| Train Set        | Portion of data used to train the model.                                   |
| Validation Set   | Portion of data used to tune model parameters.                             |
| Test Set         | Portion of data used to evaluate final model performance.                  |
| Accuracy         | Fraction of correct predictions out of total predictions.                  |
| Precision        | Fraction of relevant positive predictions out of all positive predictions. |
| Recall           | Fraction of relevant positive predictions that were correctly predicted.   |
| F1 Score         | Harmonic mean of precision and recall.                                     |
| Confusion Matrix | Table showing correct and incorrect predictions across classes.            |
| Cross-Validation | Technique to assess model performance by splitting data multiple times.    |


## 5 Model Behavior Terms

| Term                   | Description                                                                  |
| ---------------------- | ---------------------------------------------------------------------------- |
| Overfitting            | Model memorizes training data and fails to generalize.                       |
| Underfitting           | Model fails to capture patterns in data.                                     |
| Bias                   | Error from oversimplifying the model.                                        |
| Variance               | Error from the model being too sensitive to training data.                   |
| Bias-Variance Tradeoff | Balancing simplicity (bias) and flexibility (variance) for best performance. |


## 6 Basic Algorithms

| Term                         | Description                                                |
| ---------------------------- | ---------------------------------------------------------- |
| Linear Regression            | Predicts continuous output assuming a linear relationship. |
| Logistic Regression          | Predicts probabilities for classification tasks.           |
| K-Nearest Neighbors (KNN)    | Predicts based on the closest examples in training data.   |
| Decision Tree                | Splits data based on features to make predictions.         |
| Random Forest                | Ensemble of decision trees to improve accuracy.            |
| Support Vector Machine (SVM) | Finds the best boundary separating classes.                |
| Naive Bayes                  | Probabilistic classifier based on Bayes’ theorem.          |


## 7 Optimization & Training Terms

| Term             | Description                                                  |
| ---------------- | ------------------------------------------------------------ |
| Loss Function    | Measures how far predictions are from actual labels.         |
| Cost Function    | Overall measure of model error across dataset.               |
| Error            | Difference between predicted and actual values.              |
| Gradient         | Direction to adjust model parameters to reduce error.        |
| Gradient Descent | Method to minimize loss by updating parameters step by step. |
| Learning Rate    | Step size in updating model parameters.                      |
| Epoch            | One complete pass through the training dataset.              |
| Iteration        | Single update step in training (may use a subset of data).   |


## 8 Feature Engineering Terms

| Term             | Description                                           |
| ---------------- | ----------------------------------------------------- |
| Feature Scaling  | Adjusting feature values to a common range.           |
| Normalization    | Scaling data between 0 and 1.                         |
| Standardization  | Scaling data to have mean 0 and standard deviation 1. |
| Encoding         | Converting categorical variables into numeric form.   |
| One-Hot Encoding | Encoding categorical variables as binary vectors.     |
| Missing Values   | Gaps in the dataset where data is absent.             |
| Imputation       | Filling missing values using statistical methods.     |


## 9 Math Words

| Term               | Description                                        |
| ------------------ | -------------------------------------------------- |
| Probability        | Likelihood of an event occurring.                  |
| Statistics         | Collecting, analyzing, and interpreting data.      |
| Mean               | Average of a set of numbers.                       |
| Variance           | Measure of how spread out the data is.             |
| Standard Deviation | Square root of variance; spread of data.           |
| Correlation        | Relationship between two variables.                |
| Distribution       | How data values are spread across possible values. |
